## 一、内容要求

1. **三线还原**：语音稿负责“老师说了什么”，关键帧负责“黑板上写了什么”，PPT 负责“课件呈现了什么”。三者冲突时以板书/PPT 为准，并在文中注明依据的是哪一帧画面。
2. **语音稿必须全量读取**，不得遗漏任何段落。
3. 语音稿是自动转写，存在系统性同音错字（例如“举证→矩阵”“转制→转置”“内机→内积”“现金代数→线性代数”“对焦化→对角化”）。引用老师原话时必须改写为规范数学术语，**绝对不能把错字原样抄进讲义**；听不清或术语可疑的地方一律以板书/PPT 为准。
4. **每个知识板块都要引用老师原话**并标注录音时间，格式 `[录音 mm:ss]`，全篇不少于 15 处。
5. **每一块板书或 PPT 都要标注画面时间**，格式 `[画面 mm:ss]`，并写清楚板书/幻灯片上的具体公式、符号与下标。
6. **例题必须标明是否为课堂上讲过**：课堂例题写“课堂讲授”并给时间戳；讲义自编例题写“讲义例题”。
7. **推导要完整**：每一个结论都要有详细的推导过程，做到课堂上可以照着仔细思考，不能只给结论。
8. **不要换页、不要留白**：章节之间连续排版，不得为了美观强行分页；不得出现只有几行字的空白页。
9. 目录页码必须与实际排版一致。

## 二、技术路线（硬性，不得更改）

1. **纯 HTML + CSS 排版**，用 Chromium / Playwright 无头浏览器打印成 **A4 黑白 PDF**（适合黑白激光打印机，不依赖任何颜色区分信息）。
2. **严禁任何 LaTeX 路线**：不得调用 `xelatex` / `pdflatex` / `lualatex` / `tectonic` / `xdvipdfmx`；不得把旧的 LaTeX 版 PDF 整页转图或嵌入；不得输出 `.tex`。
3. **公式用 MathJax 3，输出 CHTML（不是 SVG）**：

   ```html
   <script>
   MathJax = { tex: { inlineMath: [['\\(','\\)']], displayMath: [['\\[','\\]']] },
               chtml: { scale: 1.0, displayAlign: 'left' },
               options: { enableMenu: false } };
   </script>
   <script id="MathJax-script" async src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js"></script>
   ```

   打印前必须等待 `MathJax.startup.promise` 完成，否则公式会缺失。
4. **所有插图用内联 SVG 手绘**，不得用位图、截图、外链图片。
5. **只交付最终 PDF 一个附件**，不要交付 HTML、tex、py、图片或压缩包。

## 三、设计规范（黑白专用，逐条落实）

> 黑白版的核心约束：**去掉颜色后，所有信息层级仍然清楚**。不能用颜色作为唯一区分手段，必须同时用线型、灰度、符号、文字标签。

### 3.1 页面与版式
- 纸张 A4（210 × 297 mm），`printBackground: true`。
- 页边距：上 18 mm、下 15 mm、左 18 mm、右 18 mm。
- 正文 10.5 pt，行高 1.7，颜色 `#111111`，两端对齐。
- 中文字体：`"Source Han Serif SC", "Noto Serif CJK SC", "SimSun"`；标题用 `"Source Han Sans SC", "Microsoft YaHei"`。
- 页眉：左侧「{{课程名}} · {{讲次}}」，右侧当前章节名，下方 0.6 pt 黑线。
- 页脚：左「课堂录音逐句整理 · 三级标注讲义」，右「第 X / Y 页」。
- 用 Playwright 的 `displayHeaderFooter` + `headerTemplate` / `footerTemplate`；若用 Chromium 命令行，用 `@page` + 固定页脚元素。
- 全局 `-webkit-print-color-adjust: exact; print-color-adjust: exact;`。

### 3.2 灰度体系（写成 CSS 变量，全站只引用变量）
```css
:root{
  --black:#000000; --ink:#111111; --gray-7:#333333; --gray-5:#555555;
  --gray-4:#777777; --gray-3:#999999; --gray-2:#c8c8c8; --gray-1:#e8e8e8;
  --bg-1:#f5f5f5;  --bg-2:#ebebeb;  --bg-3:#dedede;  --white:#ffffff;
  --rule:#bfbfbf;
}
```
- **禁止出现任何彩色**：不得写 `#1d4ed8`、`hsl(...)` 等彩色值；不得用 emoji 彩色图标。
- 灰度层次只允许上述 4 档（`--gray-7` / `--gray-5` / `--gray-3` / `--gray-1`）+ 3 档浅底，避免打印后糊成一片。

### 3.3 封面
- 顶部一块纯黑（`--black`）色块，占页面宽度 100%、高度约 65 mm，白字。
- 英文小标题：9 pt，字距 0.16 em，白色 75%。
- 主标题：课程名，40 pt，粗体，白色。
- 副标题：`{{讲次}}：<本讲主题>`，18 pt，白色。
- 一句话内容梗概，11 pt，白色 85%。
- 封面下方一张信息表：课程名 / 讲次 / 讲授人 / 教材范围 / 素材来源 / 覆盖节数 / 输出格式（写“A4 黑白 PDF”）。
- 「本讲速览」卡片：主线一句话 + 收录内容统计（节数、例题数、插图数、时间戳数量）。
- 「标注体系说明」：说明四种符号标签各代表什么。
- 最后「本讲目录」：两级目录，带页码。

### 3.4 章节标题
- 结构：`序号徽章` + `标题` + `右侧 pill 标签`。
- 序号用黑底白字圆形徽章（22 pt），标题 20–22 pt 粗体。
- 标题左侧加 5 px 黑色竖条（`border-left`）。
- 上方留 18 pt、下方留 8 pt，**不要 `page-break-before`**。

### 3.5 内容盒子（靠线型 + 灰度区分，不得只靠颜色）
| 盒子 | 用途 | 背景 | 边框 | 右上标签 |
|---|---|---|---|---|
| 定义框 | 定义、概念 | `--white` | 1.5 px 实线黑，左侧 6 px 黑条 | 定义 |
| 定理框 | 定理、性质、结论 | `--bg-1` | 1.5 px 双线（`border:3px double #000`） | 定理 |
| 方法小结 | 解题套路、口诀 | `--bg-2` | 1.5 px 虚线（`dashed`） | 方法小结 |
| 易错点 | 常见错误、反例 | `--bg-3` | 2 px 实线黑 + 左上角黑色三角标记 | 易错点 |
| 考点提示 | 老师暗示可能考 | `--bg-1` | 2 px 实线黑，右侧 6 px 黑条 | 考点提示 |
| 老师原话 | 逐字引用 | `--white` | 1.2 px 左侧点线（`dotted`），正文斜体 | 老师原话 |
| 例题框 | 题目+解答 | `--white` | 1 px 黑全边框 | 例题 X.Y |

盒子统一：圆角 3 px、内边距 8 mm 6 mm、`break-inside: avoid`。

### 3.6 符号标签（替代四色标签）
统一做成白底黑边胶囊（`border:1.2px solid #000; border-radius:999px`，8 pt，黑字），用**符号 + 文字**区分，四种固定搭配：
- ● 课堂讲授
- ▲ 定理定义
- ■ 重点
- ◆ 可能考

正文中凡是老师讲过的例题、强调过的结论、暗示会考的点，**必须在句子后面挂对应标签**。

### 3.7 表格
- 表头：纯黑底白字，10 pt。
- 奇数行 `--bg-1`，隔行变灰。
- 边框：外框 1.2 px 黑，内部只用 0.8 px `--rule` 横线，不要竖线。
- 数字右对齐，文字左对齐。

### 3.8 插图（内联 SVG，黑白）
- 统一 `viewBox`，宽度 100%，高度自适应，居中。
- 顶点：白底 + 1.6 px 黑描边；标签黑色，字号 ≥ 9 pt。
- 边：1.4 px 黑；树边实线、非树边虚线（`stroke-dasharray:4 3`）。
- 需要填充区分时只用灰度（`#ffffff` / `#d9d9d9` / `#a6a6a6`）或斜线纹理，**不得用彩色**。
- 标签不得压线、不得重叠；有向图必须画黑色箭头（`marker-end`）。
- 每幅图下方必须有图注：`图 X-Y 说明文字`。

### 3.9 分页控制
```css
.box, table, figure { break-inside: avoid; }
h2, h3 { break-after: avoid; }
p { orphans: 2; widows: 2; }
```
- 章节之间**不强制分页**。
- 打印后逐页检查：不得有内容不足 200 字的尾页；不得出现半截表格。

## 四、公式与描边（最高优先级硬约束）

1. **MathJax 必须用 CHTML 输出**，禁止 `tex-svg.js`。SVG 输出的字形是路径，打印时会被 Chromium 写成同色发丝描边，放大后公式呈空心轮廓/毛边。
2. **全站禁止任何文字描边**：
   - 不得出现 `-webkit-text-stroke`
   - 不得出现 `paint-order: stroke`
   - 不得用 `text-shadow` 模拟描边或加粗
   - 不得给 `<path>` / `<use>` / `<g>` 设置 `stroke-width > 0` 用于文字
3. **页面上正常的线条描边不受限制**：示意图的顶点圆圈、连线、表格框线可以有描边，这是图形不是文字。
4. **交付前必须做三项实测，并把结果写进回复**：
   - `pdffonts` 显示公式使用真实字体（Type0 / TrueType），且文档内 SVG 公式路径数量为 0；
   - 遍历页面内容流，文字块（`BT…ET`）内的 `S` / `B` 描边算子数量为 **0**，文字渲染模式 `Tr` 全为默认值 0；
   - 抽 3 页以 400 dpi 渲染，肉眼确认公式是干净的单色实心笔画，无空心轮廓、无毛边。
5. **黑白专项实测**：把每页渲染为 RGB 检查，彩色像素（`max(R,G,B) − min(R,G,B) > 10`）占比必须为 **0**；若出现任何彩色，说明有样式漏了灰度化，改完重导。
6. 如果任何一项不通过，**不要交付**。

## 五、目录页码（必须准确）

Chromium 不支持 CSS `target-counter`，用两遍法：
1. 第一次把目录页码留空打印（或直接在浏览器里量）。
2. 用 JS 遍历每个 `h2` 的 `offsetTop`，按「每页可用高度 = 297mm − 上 18mm − 下 15mm」换算成页码，回填目录。
3. 第二次打印出最终 PDF。
4. 抽查目录前 5 条与实际页脚页码是否一致。

## 六、打印流程（必须按此执行）

```js
// Playwright
await page.waitForFunction(() => window.MathJax && MathJax.startup && MathJax.startup.promise);
await page.evaluate(() => MathJax.startup.promise);
await page.pdf({
  path: "out.pdf",
  format: "A4",
  printBackground: true,
  margin: { top: "18mm", bottom: "15mm", left: "18mm", right: "18mm" },
  displayHeaderFooter: true,
  headerTemplate: headerHTML,
  footerTemplate: footerHTML,
  preferCSSPageSize: false
});
```

- 若沙箱内没有 Playwright：`chromium --headless=new --no-sandbox --disable-gpu --print-to-pdf=out.pdf --no-pdf-header-footer file:///abs/path.html`，并在 CSS 里写 `@page { size: A4; margin: 18mm 18mm 15mm 18mm; }`。
- 打印后必须用 `pymupdf` 统计页数、逐页提取文本，确认没有空白页、没有内容溢出。
- 再逐页渲染检查灰度：如发现彩色像素，回到 CSS 排查彩色值。
