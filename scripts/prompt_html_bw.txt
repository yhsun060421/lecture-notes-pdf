## 一、内容要求

1. **三线还原**：语音稿负责“老师说了什么”，关键帧负责“黑板上写了什么”，PPT 负责“课件呈现了什么”。三者冲突时以板书/PPT 为准，并在文中注明依据的是哪一帧画面。
2. **语音稿必须全量读取**，不得遗漏任何段落。
3. 语音稿是自动转写，存在系统性同音错字（例如“举证→矩阵”“转制→转置”“内机→内积”“现金代数→线性代数”“对焦化→对角化”）。引用老师原话时必须改写为规范数学术语，**绝对不能把错字原样抄进讲义**；听不清或术语可疑的地方一律以板书/PPT 为准。
4. **每个知识板块都要引用老师原话**并标注录音时间，格式 `[录音 mm:ss]`，全篇不少于 15 处。
5. **每一块板书或 PPT 都要标注画面时间**，格式 `[画面 mm:ss]`，并写清楚板书/幻灯片上的具体公式、符号与下标。
6. **例题必须标明是否为课堂上讲过**：课堂例题写“课堂讲授”并给时间戳；讲义自编例题写“讲义例题”。
7. **推导要完整**：每一个结论都要有详细的推导过程，做到课堂上可以照着仔细思考，不能只给结论。
8. **不得摘要、不得压缩**：宁可页数多，不许合并小节、删例题、把推导写成“易得”。
9. **不要换页、不要留白**：章节之间连续排版，不得为了美观强行分页；不得出现只有几行字的空白页。
10. 目录页码必须与实际排版一致。

## 二、技术路线（硬性，不得更改）

1. **纯 HTML + CSS 排版**，用 Chromium / Playwright 无头浏览器打印成 **A4 黑白 PDF**。
2. **严禁任何 LaTeX 路线**：不得调用 `xelatex` / `pdflatex` / `lualatex` / `tectonic` / `xdvipdfmx`；不得输出 `.tex`；不得把图片整页贴进 PDF。
3. **所有数学公式一律用 MathJax 3 渲染 TeX 源码**，输出 CHTML：

   ```html
   <script>
   window.MathJax = {
     tex: { inlineMath: [['\\(','\\)']], displayMath: [['\\[','\\]']], processEscapes: true, tags: 'none' },
     chtml: { scale: 1.0, mtextInheritFont: true },
     options: { enableMenu: false }
   };
   </script>
   <script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js" id="MathJax-script" async></script>
   ```

   打印前必须等待 `MathJax.startup.promise`，否则公式会缺失。行内、行间公式一律写 TeX，不用字符拼凑。
4. **所有插图用内联 SVG 手绘**，灰度填充/描边；不得用位图、截图、外链图片。
5. **只交付最终 PDF 一个附件**。

## 三、设计规范（黑白版）

### 3.1 页面与版式
- A4，`printBackground: true`。
- 页边距：上 18 mm、下 15 mm、左 18 mm、右 18 mm（黑白版比彩色版略宽，防止黑块压边）。
- 正文 10.4 pt / 行高 1.74，两端对齐；字体同彩色版（正文衬线，标题黑体）。
- 页眉左「{{课程名}} · {{讲次}}」，右当前章名，下缘 0.6 pt `#999` 细线；页脚右「第 X / Y 页」。
- `-webkit-print-color-adjust: exact; print-color-adjust: exact;`。

### 3.2 灰阶令牌（全部 `R=G=B`，不得出现任何色相）
```css
:root{
  --ink:#111; --ink-2:#333; --mid:#444; --soft:#666; --hair:#cfcfcf;
  --dark:#1a1a1a;  --dark-2:#2e2e2e;
  --g-blue:#3a3a3a;  --g-blue-bg:#ededed;   /* 对应彩色 --blue / --blue-bg */
  --g-teal:#4a4a4a;  --g-teal-bg:#f1f1f1;   /* 对应 --teal / --teal-bg */
  --g-crimson:#222;  --g-crimson-bg:#ececec;/* 对应 --crimson / --crimson-bg */
  --g-amber:#5a5a5a; --g-amber-bg:#f3f3f3;  /* 对应 --amber / --amber-bg */
  --g-slate:#6e6e6e; --g-slate-bg:#f5f5f5;  /* 对应 --slate / --slate-bg */
}
```
**判定标准**：成品 PDF 任意一页，凡像素 `max(R,G,B) − min(R,G,B) > 10` 都算彩色，占比必须为 0。emoji、彩色 SVG、半透明彩色阴影一律禁止。

### 3.3 封面
- 顶部通栏深灰块（`--dark`），左侧 3.2 mm 纯黑竖条（用黑而非金）；白字。
- 小标 9.2 pt 字距 0.34 em，颜色 `#c8c8c8`；主标题 40 pt 白色粗体；「{{讲次}}」22 pt 白字（不用彩色强调，改用上方 1 px 白线与之分隔）；主线一行 12 pt `#d8d8d8`。
- 信息表：th 26 mm 宽、`--ink`，行间 0.7 px `--hair`。
- 「标注体系」框：`border-left:3mm solid var(--dark)`，2×2 网格；标签一律白底黑框黑字（见 3.7）。
- 封底页脚 2 px 黑线 + 两行说明。
- 封面高度 262 mm，`break-after: page`。

### 3.4 目录
- 标题「目　　录」20 pt，下方 2.5 px 黑线。
- 一级条目：序号 `#000` 粗体，点线引导，页码右对齐；二级缩进 11 mm，序号 `--soft`。
- 目录单独成页。

### 3.5 章节条与标题
- 章节条：黑底（`--dark`）白字，左侧 3.2 mm 纯黑竖条；上排英文 8 pt，字距 0.3 em，色 `#c8c8c8`；下排章名 19 pt 粗体，右侧浅灰节号。
- 章节条不强制分页，`break-after: avoid`。
- `h2`：14.4 pt，左侧 2.2 mm 黑竖条，序号灰色小字在前；`h3`：11.8 pt，下缘 0.8 px `--hair`。
- 节首 `.lead` 导语 10.8 pt `--mid`。

### 3.6 盒子系统（黑白版靠**边框样式 + 标题栏灰度**区分，不靠颜色）
| 类名 | 用途 | 标题栏 | 正文区 | 边框 |
|---|---|---|---|---|
| `.thm` | 定义、定理 | `--g-blue` 实底白字 | `--g-blue-bg` | 0.9 px solid `--g-blue` |
| `.board` | 板书 / 关键帧 | `--g-teal` 实底白字 | `--g-teal-bg` | 0.9 px solid `--g-teal`，正文区左缘 2 mm 黑竖条 |
| `.exam` | 例题 + 解答 | `--g-crimson` 实底白字 | `--g-crimson-bg` | 1.4 px solid `#222`（最粗，第一眼能认出是题） |
| `.warn` | 易错点 | `--g-amber` 实底白字 | `--g-amber-bg` | 0.9 px dashed `--g-amber` |
| `.note` | 整理说明 | `--g-slate` 实底白字 | `--g-slate-bg` | 0.7 px dotted `--g-slate` |
- 结构同彩色版：`.box > .bh（标题栏）+ .bb（正文）`；标题栏左侧 3 mm 白色半透明竖条。
- 盒子间距 4 mm，`break-inside: avoid`。
- 例题的题目、解、方法小结放在同一个 `.exam` 里。

### 3.7 标签（黑白版）
- `.tag`：7.8 pt，白底 + 0.7 px 黑框 + 黑字（默认）。
- 变体：`.solid`（黑底白字，用于「课堂讲授」「可能考」）、`.outline-d`（0.7 px 虚线框，用于「重点」）。
- 用**文字本身**区分语义，不靠颜色：课堂讲授 / 定理定义 / 重点 / 可能考。

### 3.8 引语与时间戳
- `.quote`：左侧 3 px 黑竖线，底色 `#f7f7f7`，正文 `--mid`。
- `.ts`：8.4 pt `#333`，加 0.4 px 下划线式的 `text-underline-offset`；画面时间用 `[画面 mm:ss]`，同样灰阶。

### 3.9 表格
- 表头黑底白字；正文隔行 `#f4f4f4`；只保留 0.6 px 横线 `--hair`，无竖线。
- 表题在表上方 8.6 pt 黑字。

### 3.10 插图（内联 SVG，灰度）
- 顶点：白填充 + 1.8 px `#111` 描边，标签居中；有向边必须有箭头。
- 用**线型**区分语义：实线 = 主结构，粗实线 = 已选/高亮，虚线 = 候选，点线 = 辅助。
- **禁止任何彩色填充**；灰阶填充只能用 `#fff` / `#eee` / `#ddd` / `#bbb` / `#111`。
- 标签不得压线、不得压顶点；图注 `图 X-Y` 在下方。

### 3.11 分页控制
```css
.box, table, figure { break-inside: avoid; }
h2, h3, .chap { break-after: avoid; }
p { orphans: 2; widows: 2; }
```
- 章节之间不强制分页；逐页检查不得有空白尾页、半截表格、半截盒子。

## 四、公式与描边（最高优先级硬约束）

1. **MathJax 必须用 CHTML 输出**，禁止 `tex-svg.js`（SVG 字形是路径，打印会带同色发丝描边，放大后空心）。
2. **全站禁止任何文字描边**：无 `-webkit-text-stroke`、无 `paint-order: stroke`、无 `text-shadow` 描边。
3. 正常图形描边不受限制。
4. **交付前三项实测**：
   - `pdffonts` 显示公式用真实字体（Type0 / TrueType），文档内 SVG 公式路径为 0；
   - 文字块（`BT…ET`）内 `S` / `B` 描边算子为 **0**，`Tr` 全为 0；
   - 抽 3 页 400 dpi 渲染，肉眼确认公式为干净单色实心笔画。
5. **灰度实测**：随机抽 5 页渲染，统计 `max(R,G,B) − min(R,G,B) > 10` 的像素占比，必须为 **0**。

## 六、打印流程（必须按此执行）

```js
await page.waitForFunction(() => window.MathJax && MathJax.startup && MathJax.startup.promise);
await page.evaluate(() => MathJax.startup.promise);
await page.pdf({
  path: "out.pdf",
  format: "A4",
  printBackground: true,
  margin: { top: "18mm", bottom: "15mm", left: "18mm", right: "18mm" },
  displayHeaderFooter: true,
  headerTemplate: headerHTML,
  footerTemplate: footerHTML,
  preferCSSPageSize: false
});
```

- 无 Playwright 时用 `chromium --headless=new --no-sandbox --disable-gpu --print-to-pdf=out.pdf --no-pdf-header-footer file:///abs/path.html`，CSS 写 `@page { size:A4; margin:18mm 18mm 15mm 18mm; }`。
- 打印后用 pymupdf 统计页数、逐页取文本，确认无空白页、无溢出。
