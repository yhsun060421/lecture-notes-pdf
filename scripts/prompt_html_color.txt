## 一、内容要求

1. **三线还原**：语音稿负责“老师说了什么”，关键帧负责“黑板上写了什么”，PPT 负责“课件呈现了什么”。三者冲突时以板书/PPT 为准，并在文中注明依据的是哪一帧画面。
2. **语音稿必须全量读取**，不得遗漏任何段落。
3. 语音稿是自动转写，存在系统性同音错字（例如“举证→矩阵”“转制→转置”“内机→内积”“现金代数→线性代数”“对焦化→对角化”）。引用老师原话时必须改写为规范数学术语，**绝对不能把错字原样抄进讲义**；听不清或术语可疑的地方一律以板书/PPT 为准。
4. **每个知识板块都要引用老师原话**并标注录音时间，格式 `[录音 mm:ss]`，全篇不少于 15 处。
5. **每一块板书或 PPT 都要标注画面时间**，格式 `[画面 mm:ss]`，并写清楚板书/幻灯片上的具体公式、符号与下标。
6. **例题必须标明是否为课堂上讲过**：课堂例题写“课堂讲授”并给时间戳；讲义自编例题写“讲义例题”。
7. **推导要完整**：每一个结论都要有详细的推导过程，做到课堂上可以照着仔细思考，不能只给结论。
8. **不得摘要、不得压缩**：这一节讲了多少内容就写多少内容，宁可页数多，不许为省篇幅合并小节、删例题、把推导写成“易得”。
9. **不要换页、不要留白**：章节之间连续排版，不得为了美观强行分页；不得出现只有几行字的空白页。
10. 目录页码必须与实际排版一致。

## 二、技术路线（硬性，不得更改）

1. **纯 HTML + CSS 排版**，用 Chromium / Playwright 无头浏览器打印成 **A4 彩色 PDF**。
2. **严禁任何 LaTeX 路线**：不得调用 `xelatex` / `pdflatex` / `lualatex` / `tectonic` / `xdvipdfmx`；不得把旧的 LaTeX 版 PDF 整页转图或嵌入；不得输出 `.tex`。
3. **所有数学公式一律用 MathJax 3 渲染 TeX 源码**（与样板一致），输出 CHTML（不是 SVG）：

   ```html
   <script>
   window.MathJax = {
     tex: { inlineMath: [['\\(','\\)']], displayMath: [['\\[','\\]']], processEscapes: true, tags: 'none' },
     chtml: { scale: 1.0, mtextInheritFont: true },
     options: { enableMenu: false }
   };
   </script>
   <script src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js" id="MathJax-script" async></script>
   ```

   打印前必须等待 `MathJax.startup.promise` 完成，否则公式会缺失。
   **凡是数学符号（含行内的 \(x\)、\(\lambda\)、上下标、分式、矩阵）都必须写成 TeX，不许用半角字符拼凑或图片代替。**
4. **所有插图用内联 SVG 手绘**，不得用位图、截图、外链图片。
5. **只交付最终 PDF 一个附件**，不要交付 HTML、tex、py、图片或压缩包。

## 三、设计规范（以样板为准，这里只列要点）

### 3.1 页面与版式
- A4（210 × 297 mm），`printBackground: true`。
- 页边距：上 18 mm、下 16 mm、左 16 mm、右 16 mm（与样板 `@page` 一致）。
- 正文 10.4 pt / 行高 1.74，两端对齐，字距 `font-kerning: normal`。
- 正文字体 `"Source Han Serif SC","Noto Serif SC","Songti SC","SimSun",serif`；标题 `"Source Han Sans SC","Noto Sans SC","Microsoft YaHei",sans-serif`。
- 页眉：左侧「{{课程名}} · {{讲次}}」，右侧当前章名，下方 0.6 pt 浅灰线；页脚右侧「第 X / Y 页」。
- 用 Playwright 的 `displayHeaderFooter` + `headerTemplate` / `footerTemplate` 实现（`pageNumber` / `totalPages`）；若用 Chromium 命令行，则改用 `@page` 边距 + 打印后补页码，并核对。
- 全局 `-webkit-print-color-adjust: exact; print-color-adjust: exact;`，否则底纹会变白。

### 3.2 设计令牌（直接抄样板，不得改值）

:root{
  --navy:#0d1f33;  --navy2:#142d48;  --gold:#f0a03c;  --gold-l:#f5bf6a;

### 3.3 封面
- 顶部深蓝色块（`--navy`）通栏，左侧 3.2 mm 金色竖条（`--gold`）。
- 英文小标（`LECTURE NOTES · 年份`）9.2 pt，字距 0.34 em，颜色 `--gold-l`。
- 主标题课程名 40 pt 白色粗体；下方「{{讲次}}」22 pt，颜色 `--gold`；再下面一行本节主线（用 · 分隔）12 pt，浅灰。
- 深色块下方是信息表：课程名称 / 课次 / 授课人 / 教材范围 / 素材来源 / 输出格式（`table.meta`，th 26 mm 宽、`--navy` 字色，行间 0.7 px `--hair` 细线）。
- 再下方「标注体系」框：`border-left:3mm solid var(--navy)`，2×2 网格列出四类标签及释义。
- 页脚：左两行说明，右「讲义」字样，上方 2 px 实线。
- 封面高度 262 mm，`break-after: page`。

### 3.4 目录
- 标题「目　　录」20 pt，`--navy`，下方 2.5 px 实线。
- 一级条目：序号金色（`--gold`）粗体，标题正文大小，点线引导（`border-bottom:1px dotted #b9c2cc`），页码右对齐 `--navy`。
- 二级条目缩进 11 mm，序号灰色小号，标题 9.6 pt `--mid`。
- 目录单独成页。

### 3.5 章节条与标题
- 章节条 `.chap`：深蓝底、白字、左侧 3.2 mm 金色条；上排英文 `C H A P T E R   0 1` 8 pt `--gold-l` 字距 0.3 em；下排章节名 19 pt 粗体，右侧浅灰小字放教材节号。
- **章节条不强制分页**，自然接在上一节内容后面；但章节条后至少要有两行正文（`break-after: avoid`）。
- `h2`：14.4 pt `--navy`，左侧 2.2 mm 金色竖条，序号 `1.1` 灰色 9.4 pt 在前。
- `h3`：11.8 pt，下缘 0.8 px `--hair` 细线。
- 节首可加一段 `.lead` 导语（10.8 pt `--mid`），说明本节要解决什么问题。

### 3.6 盒子系统（核心，五类，不得混用）
统一结构：

```html
<div class="box thm">          <!-- thm / board / exam / warn / note -->
  <div class="bh"><span class="l">定 理 1.1　（定理名）</span><span class="r">定理 · 定义</span></div>
  <div class="bb"> …正文… </div>
</div>
```

| 类名 | 用途 | 主色 | 底色 | 标题栏右侧文字 |
|---|---|---|---|---|
| `.thm` | 定义、定理、性质 | `--blue` | `--blue-bg` | 定理 · 定义 |
| `.board` | 板书内容 / 关键帧 | `--teal` | `--teal-bg` | 板书 · 关键帧 |
| `.exam` | 例题 + 解答 | `--crimson` | `--crimson-bg` | 例题 · 课堂 |
| `.warn` | 易错点、反例 | `--amber` | `--amber-bg` | 重点 |
| `.note` | 整理说明、来源核对 | `--slate` | `--slate-bg` | 整理说明 |

- 标题栏是 **实色通栏**（主色底 + 白字），左侧 3 mm 白色半透明竖条；正文区是浅色底 + 0.8 px 主色边框。
- 盒子间距 4 mm，`break-inside: avoid`，盒子内最后一个元素不留下边距。
- 例题的「题目」「解」「方法小结」在同一个 `.exam` 里，用加粗小标题分段，不要拆成多个盒子。

### 3.7 标签
- `.tag`：7.8 pt，白底细边（默认 `--slate`）；变体 `.navy`（深蓝实底白字）、`.gold`（金底深字）、`.crimson`（绛红实底白字）、`.blue`。
- 用途固定：课堂讲授 → `.navy`；重点 → `.gold`；可能考 → `.crimson`；定理定义 → `.blue`。
- 标签挂在句子末尾或盒子标题里，不要散落成装饰。

### 3.8 引语与时间戳
- 老师原话用 `.quote`：左侧 3 px `--gold` 竖线，底色 `#fffaef`，正文 `--mid`。
- 时间戳 `.ts`：8.4 pt，`--blue`；画面时间用 `.ts.frame`（`--teal`）。格式固定 `[录音 12:34]`、`[画面 24:40]`。

### 3.9 表格
- 表头深蓝底白字（`--navy`），单元格 9.2–9.4 pt。
- 隔行浅灰 `#f7f9fb`；只用 0.6 px 横线（`--hair`），**不要竖线**。
- 表题在表上方（`caption`，8.6 pt `--navy`，字距 0.12 em）。
- 数字列居中/右对齐，文字列左对齐。

### 3.10 插图（内联 SVG）
- 统一 `viewBox`，`max-width:100%`，居中；图注在下方 `图 X-Y 说明`，`b` 用 `--navy`。
- 顶点：白填充 + 1.8 px `--navy` 描边，标签居中在圆内；有向边必须 `marker-end` 箭头。
- 配色按语义：主结构 `--blue`、已选/高亮 `--gold`、候选/虚线 `--teal`、辅助 `--slate`。
- **标签不得压线、不得压顶点**；密度大时把文字移到空白象限，必要时加引线。
- 图必须与正文数据完全一致（顶点数、边数、权值、方向），画不出就别用文字糊弄。

### 3.11 分页控制
```css
.box, table, figure { break-inside: avoid; }
h2, h3, .chap { break-after: avoid; }
p { orphans: 2; widows: 2; }
```
- 章节之间不强制分页，靠内容自然流动。
- 打印后逐页检查：不得出现内容不足 200 字的尾页，不得有半截表格、半截盒子。

## 四、公式与描边（最高优先级硬约束）

1. **MathJax 必须用 CHTML 输出**，禁止 `tex-svg.js`。SVG 输出的字形是路径，打印时会被 Chromium 写成同色发丝描边，放大后公式呈空心轮廓/毛边。
2. **全站禁止任何文字描边**：不得出现 `-webkit-text-stroke`、`paint-order: stroke`、用 `text-shadow` 模拟描边或加粗，也不得给 `<path>` / `<use>` / `<g>` 设置 `stroke-width > 0` 去描文字。
3. **正常图形描边不受限制**：顶点圆圈、连线、表格框线可以有描边。
4. **交付前必须做三项实测，并把结果写进回复**：
   - `pdffonts` 显示公式使用真实字体（Type0 / TrueType），文档内 SVG 公式路径数量为 0；
   - 遍历页面内容流，文字块（`BT…ET`）内的 `S` / `B` 描边算子数量为 **0**，文字渲染模式 `Tr` 全为默认值 0；
   - 抽 3 页以 400 dpi 渲染，肉眼确认公式是干净的单色实心笔画，无空心轮廓、无毛边。
5. 任何一项不通过就不要交付，改完重新导出。

## 六、打印流程（必须按此执行）

```js
// Playwright
await page.waitForFunction(() => window.MathJax && MathJax.startup && MathJax.startup.promise);
await page.evaluate(() => MathJax.startup.promise);
await page.pdf({
  path: "out.pdf",
  format: "A4",
  printBackground: true,
  margin: { top: "18mm", bottom: "16mm", left: "16mm", right: "16mm" },
  displayHeaderFooter: true,
  headerTemplate: headerHTML,
  footerTemplate: footerHTML,
  preferCSSPageSize: false
});
```

- 沙箱无 Playwright 时：`chromium --headless=new --no-sandbox --disable-gpu --print-to-pdf=out.pdf --no-pdf-header-footer file:///abs/path.html`，CSS 里写 `@page { size: A4; margin: 18mm 16mm 16mm 16mm; }`，打印后用 pymupdf 补页码。
- 打印后必须用 `pymupdf` 统计页数、逐页提取文本，确认没有空白页、没有内容溢出页边。
