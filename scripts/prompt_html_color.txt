这个视频是《{{课程名}}》课程，本次讲授为{{讲次}}，共 {{节数}} 节，已经合并成一个视频：`{{视频文件}}`。

你需要一步一步分析老师的板书图片，也就是对视频的具体关键帧进行截屏分析（如果需要视觉查看板书内容，请放大后再截图，仔细做视觉分析），然后结合老师的讲课语音信息（我下面给你这几节课程对应的语音原文，你要严格详细分析语音原文，然后与视频关键帧的板书、电脑上呈现的 PPT 进行双线分析）。也就是你要成为一个学生代替我上课，这几节课都要进行分析，详细分析文字稿。

## 一、内容要求

1. **三线还原**：语音稿负责“老师说了什么”，关键帧负责“黑板上写了什么”，PPT 负责“课件呈现了什么”。三者冲突时以板书/PPT 为准，并在文中注明依据的是哪一帧画面。
2. **语音稿必须全量读取**，不得遗漏任何段落。
3. 语音稿是自动转写，存在系统性同音错字（例如“举证→矩阵”“转制→转置”“内机→内积”“现金代数→线性代数”“对焦化→对角化”）。引用老师原话时必须改写为规范数学术语，**绝对不能把错字原样抄进讲义**；听不清或术语可疑的地方一律以板书/PPT 为准。
4. **每个知识板块都要引用老师原话**并标注录音时间，格式 `[录音 mm:ss]`，全篇不少于 15 处。
5. **每一块板书或 PPT 都要标注画面时间**，格式 `[画面 mm:ss]`，并写清楚板书/幻灯片上的具体公式、符号与下标。
6. **例题必须标明是否为课堂上讲过**：课堂例题写“课堂讲授”并给时间戳；讲义自编例题写“讲义例题”。
7. **推导要完整**：每一个结论都要有详细的推导过程，做到课堂上可以照着仔细思考，不能只给结论。
8. **不要换页、不要留白**：章节之间连续排版，不得为了美观强行分页；不得出现只有几行字的空白页。
9. 目录页码必须与实际排版一致。

## 二、技术路线（硬性，不得更改）

1. **纯 HTML + CSS 排版**，用 Chromium / Playwright 无头浏览器打印成 **A4 彩色 PDF**。
2. **严禁任何 LaTeX 路线**：不得调用 `xelatex` / `pdflatex` / `lualatex` / `tectonic` / `xdvipdfmx`；不得把旧的 LaTeX 版 PDF 整页转图或嵌入；不得输出 `.tex`。
3. **公式用 MathJax 3，输出 CHTML（不是 SVG）**：

   ```html
   <script>
   MathJax = { tex: { inlineMath: [['\\(','\\)']], displayMath: [['\\[','\\]']] },
               chtml: { scale: 1.0, displayAlign: 'left' },
               options: { enableMenu: false } };
   </script>
   <script id="MathJax-script" async src="https://cdn.jsdelivr.net/npm/mathjax@3/es5/tex-chtml.js"></script>
   ```

   打印前必须等待 `MathJax.startup.promise` 完成，否则公式会缺失。
4. **所有插图用内联 SVG 手绘**，不得用位图、截图、外链图片。
5. **只交付最终 PDF 一个附件**，不要交付 HTML、tex、py、图片或压缩包。

## 三、设计规范（逐条落实，风格必须统一）

### 3.1 页面与版式
- 纸张 A4（210 × 297 mm），`printBackground: true`。
- 页边距：上 17 mm、下 13 mm、左 15 mm、右 15 mm。
- 正文 10.5 pt，行高 1.75，颜色 `#1f2937`，两端对齐。
- 中文字体：`"Source Han Sans SC", "Noto Sans CJK SC", "Microsoft YaHei"`；正文可用 `"Source Han Serif SC"`。
- 页眉：左侧「{{课程名}} · {{讲次}}」，右侧当前章节名，下方 0.5 pt 浅灰线。
- 页脚：左「课堂录音逐句整理 · 三级标注讲义」，右「第 X / Y 页」。
- 用 Playwright 的 `displayHeaderFooter` + `headerTemplate` / `footerTemplate` 实现，页码用 `pageNumber` / `totalPages`；若用 Chromium 命令行，则改用 CSS `@page` 边距 + 页脚元素，并在打印后核对页码。
- 全局加 `-webkit-print-color-adjust: exact; print-color-adjust: exact;`，否则底纹与色块会被打印成白色。

### 3.2 配色（写成 CSS 变量，全站只引用变量）
```css
:root{
  --navy:#0f2743; --ink:#1f2937; --muted:#64748b;
  --blue:#1d4ed8;  --blue-bg:#eff6ff;  --blue-line:#bfdbfe;
  --green:#047857; --green-bg:#ecfdf5; --green-line:#a7f3d0;
  --red:#b91c1c;   --red-bg:#fef2f2;   --red-line:#fecaca;
  --amber:#b45309; --amber-bg:#fffbeb; --amber-line:#fde68a;
  --purple:#6d28d9;--purple-bg:#f5f3ff;--purple-line:#ddd6fe;
  --rule:#e5e7eb;
}
```

### 3.3 封面
- 顶部一块深蓝（`--navy`）色块，占页面宽度 100%、高度约 70 mm，白字。
- 英文小标题：9 pt，字距 0.16 em，白色 70% 透明。
- 主标题：课程名，40 pt，粗体，白色。
- 副标题：`{{讲次}}：<本讲主题>`，18 pt，白色。
- 一句话内容梗概，11 pt，白色 80%。
- 封面下方一张信息表：课程名 / 讲次 / 讲授人 / 教材范围 / 素材来源 / 覆盖节数 / 输出格式。
- 再下方「本讲速览」卡片：主线一句话 + 收录内容统计（节数、例题数、插图数、时间戳数量）。
- 再下方「标注体系说明」：四色标签各是什么意思。
- 最后「本讲目录」：两级目录，带页码。

### 3.4 章节标题
- 结构：`序号徽章` + `标题` + `右侧 pill 标签`。
- 序号用蓝底白字圆形徽章（22 pt），标题 20–22 pt 粗体。
- 标题左侧加 4 px 蓝色竖条（`border-left`）。
- 上方留 18 pt、下方留 8 pt，**不要 `page-break-before`**，让内容自然接续。

### 3.5 内容盒子（一类一个固定配色，不得混用）
| 盒子 | 用途 | 背景 | 左边框 | 右上标签 |
|---|---|---|---|---|
| 定义框 | 定义、概念 | `--blue-bg` | 4px `--blue` | 定义 |
| 定理框 | 定理、性质、结论 | `--green-bg` | 4px `--green` | 定理 |

### 3.6 四色标注标签
统一做成胶囊形（`border-radius:999px`，8 pt，白字，左右各 6 px）：
- 🟦 课堂讲授（蓝）
- 🟩 定理定义（绿）
- 🟥 重点（红）
- 🟪 可能考（紫）

正文中凡是老师讲过的例题、强调过的结论、暗示会考的点，**必须在句子后面挂对应标签**，不能只写在目录里。

### 3.7 表格
- 表头：深蓝底（`--navy`）白字，10 pt。
- 奇数行浅灰 `#f8fafc`，隔行变色。
- 边框只用 1 px `--rule` 横线，不要竖线。
- 数字右对齐，文字左对齐。

### 3.8 插图（内联 SVG）
- 统一 `viewBox`，宽度 100%，高度自适应，居中。
- 顶点：白色填充 + 2 px 彩色描边，标签居中在圆内，字号 ≥ 9 pt。
- 边：1.5 px；树边实线、非树边虚线（`stroke-dasharray:4 3`）。
- 配色按组区分：深蓝 `#1e40af`、赭红 `#b45309`、紫 `#6d28d9`、灰 `#94a3b8`。
- 标签不得压线、不得重叠；边上的标号要沿边线切向摆放。
- 每幅图下方必须有图注：`图 X-Y 说明文字`。
- 有向图必须画箭头（`marker-end`）。

### 3.9 分页控制
```css
.box, table, figure { break-inside: avoid; }
h2, h3 { break-after: avoid; }
p { orphans: 2; widows: 2; }
```
- 章节之间**不强制分页**，靠内容自然流动。
- 打印后逐页检查：不得有内容不足 200 字的尾页；不得出现半截表格。

## 四、公式与描边（最高优先级硬约束）

1. **MathJax 必须用 CHTML 输出**，禁止 `tex-svg.js`。SVG 输出的字形是路径，打印时会被 Chromium 写成同色发丝描边，放大后公式呈空心轮廓/毛边。
2. **全站禁止任何文字描边**：
   - 不得出现 `-webkit-text-stroke`
   - 不得出现 `paint-order: stroke`
   - 不得用 `text-shadow` 模拟描边或加粗
   - 不得给 `<path>` / `<use>` / `<g>` 设置 `stroke-width > 0` 用于文字
3. **页面上正常的线条描边不受限制**：示意图的顶点圆圈、连线、表格框线可以有描边，这是图形不是文字。
4. **交付前必须做三项实测，并把结果写进回复**：
   - `pdffonts` 显示公式使用真实字体（Type0 / TrueType），且文档内 SVG 公式路径数量为 0；
   - 遍历页面内容流，文字块（`BT…ET`）内的 `S` / `B` 描边算子数量为 **0**，文字渲染模式 `Tr` 全为默认值 0；
   - 抽 3 页以 400 dpi 渲染，肉眼确认公式是干净的单色实心笔画，无空心轮廓、无毛边。
5. 如果任何一项不通过，**不要交付**，改完重新导出。

## 五、目录页码（必须准确）

Chromium 不支持 CSS `target-counter`，用两遍法：
1. 第一次把目录页码留空打印（或直接在浏览器里量）。
2. 用 JS 遍历每个 `h2` 的 `offsetTop`，按「每页可用高度 = 297mm − 上 17mm − 下 13mm」换算成页码，回填目录。
3. 第二次打印出最终 PDF。
4. 抽查目录前 5 条与实际页脚页码是否一致。

## 六、打印流程（必须按此执行）

```js
// Playwright
await page.waitForFunction(() => window.MathJax && MathJax.startup && MathJax.startup.promise);
await page.evaluate(() => MathJax.startup.promise);
await page.pdf({
  path: "out.pdf",
  format: "A4",
  printBackground: true,
  margin: { top: "17mm", bottom: "13mm", left: "15mm", right: "15mm" },
  displayHeaderFooter: true,
  headerTemplate: headerHTML,
  footerTemplate: footerHTML,
  preferCSSPageSize: false
});
```

- 若沙箱内没有 Playwright：`chromium --headless=new --no-sandbox --disable-gpu --print-to-pdf=out.pdf --no-pdf-header-footer file:///abs/path.html`，并在 CSS 里写 `@page { size: A4; margin: 17mm 15mm 13mm 15mm; }`。
- 打印后必须用 `pymupdf` 统计页数、逐页提取文本，确认没有空白页、没有内容溢出到页边距外。
- 若某页公式缺失，说明没有等到 MathJax 渲染完成，重新打印。
