1树与生成树定理定义

本讲从「无圈连通」这个最朴素的结构出发。老师先用五个等价命题把「树」钉死，再说明为什么这五个条件在证明里可以互相顶替。[录音 03:12]

定义 1.1　树与生成树定义

不含圈的连通图称为树（tree）。若图 \(G\) 的生成子图 \(T\) 是树，则称 \(T\) 为 \(G\) 的一棵生成树（spanning tree）。

设 \(T\) 是 \(n\) 阶树，则 \(T\) 恰有 \(n-1\) 条边；反过来，\(n\) 阶连通图若有 \(n-1\) 条边，必为树。

定理 1.2　树的五个等价刻画定理

对 \(n\) 阶图 \(G\)（\(n\ge 2\)），下列命题等价：

(i) \(G\) 连通且无圈；　(ii) \(G\) 无圈且 \(m=n-1\)；　(iii) \(G\) 连通且 \(m=n-1\)；
(iv) \(G\) 中任意两顶点间恰有一条通路；　(v) \(G\) 连通，且删去任一边后不连通。

老师原话[录音 08:47]

「这五个条件你考试的时候不要背，要会用。证明题里给你哪一个，你就从哪一个出发；给的是边数，你第一反应就是归纳。」可能考

例题 1.1　（课堂讲授）课堂讲授[画面 12:30]

题：设 \(T\) 是 \(n\) 阶树，\(n\ge 2\)，证明 \(T\) 至少有两个叶子。

证：取 \(T\) 的一条最长通路 \(P=v_1v_2\cdots v_k\)。若 \(v_1\) 不是叶子，则存在与 \(v_1\) 相邻且不在 \(P\) 上的顶点 \(u\)。

\[ \begin{aligned} &\text{若 } u \notin P:\quad v_k \cdots v_2 v_1 u \text{ 比 } P \text{ 更长，矛盾};\\ &\text{若 } u \in P:\quad \text{则 } P \text{ 上出现圈，与 } T \text{ 无圈矛盾}. \end{aligned} \]

故 \(v_1\) 必为叶子；对 \(v_k\) 同理，得至少两个叶子。重点

1.2　生成树的计数：Cayley 公式

完全图 \(K_n\) 的生成树个数由 Cayley 公式给出，它是本讲唯一的计数结论，也是后面概率法的基础。

定理 1.3　Cayley 公式定理

完全图 \(K_n\) 的生成树个数为

\[ \tau(K_n) \;=\; n^{\,n-2},\qquad n\ge 2. \]

等价说法：\(n\) 个标号顶点上的树共有 \(n^{n-2}\) 棵。

方法小结　三个常用套路方法小结
  • 归纳法：对 \(n\) 归纳，删掉一个叶子把问题降一阶（上面例题 1.1 的写法）。
  • 双计数：同一集合按两种方式各数一遍，令两式相等，Cayley 公式的 Prüfer 证明即属此类。
  • 破圈法 / 避圈法：判断生成树存在性时，破圈法给出「贪心删边」的直觉依据。
易错点　边数 \(n-1\) 不能单独用易错点

「\(m=n-1\)」单独推不出树：不连通的图也可能有 \(n-1\) 条边（例如 \(K_3\) 加一个孤立点，\(n=4,\ m=3\)）。必须与「连通」或「无圈」之一同时成立。重点

另一个坑：把「生成子图」写成「子图」——生成树要求顶点集完全相同，只是边集取子集。

考点提示　本章的三种出题面考点提示

老师在本讲结尾明确说了三种题型：[录音 1:22:15]

  1. 给一张具体的图，要求写出全部生成树或数出个数——套 Cayley 公式或直接枚举。
  2. 证明「连通图必有生成树」——用破圈法写构造性证明。
  3. 给带权图求最小生成树——必须写清每一步选边的依据（割最优性）。

引理：割最优性的一个直接推论

设 \(S\subset V\)，\(\delta(S)\) 为跨割边集。若 \(e\in\delta(S)\) 是 \(\delta(S)\) 中权最小的边，则存在一棵 MST 包含 \(e\)。证明用交换论证：把 \(e\) 换进任一棵不含 \(e\) 的 MST 即可，注意换入后仍是树。

\[ w(T') \;=\; w(T) - w(f) + w(e) \;\le\; w(T),\qquad f\in\delta(S)\cap T . \]

2最小生成树课堂讲授

带权连通图 \(G=(V,E,w)\) 中，权和最小的生成树称为最小生成树（MST）。两套经典算法在同一张图上会得到同一棵（或同权）树。

表 2-1　Kruskal 与 Prim 的对照（依据 [画面 1:04:20] 板书整理）
对比项KruskalPrim
选边方式全局按权升序，逐条试加从一点出发，每次扩一条最轻的跨界边
判据两端不在同一分量（并查集）一端在树内、一端在树外
复杂度\(O(m\log m)\)\(O(m\log n)\)（二叉堆）
适用稀疏图稠密图

两者的正确性来自同一条判据：每一步选的边都是某个割上的最轻边，因此属于某棵 MST 的边集，算法结束时边数达到 \(n-1\)，即为 MST。[录音 1:11:05]

例题 2.1　（课堂讲授）[画面 1:07:30]

题：用 Kruskal 算法求图 2-1 的 MST，写出选边顺序与总权。

解：按权升序依次考察：\(AD(1)\) 取；\(AB(2)\) 取；\(DB(3)\)——此时 \(A\to D\to B\to A\) 已成圈，跳过；\(CE(4)\) 取；\(DE(7)\) 取。共 \(4=n-1\) 条边，连通全部 5 个顶点，总权 \(1+2+4+7=14\)。重点
